# ModernTD

A modern air-defense tower defense game. Stop drone swarms, cruise missiles and ballistic strikes with layered guns, lasers, jammers and SAMs across six theaters.

**Play:** open `index.html` in a browser, or visit the GitHub Pages site for this repository.

On iPhone or iPad, open the site in Safari, tap Share, then "Add to Home Screen" to install it as a full-screen app that works offline.

The game is a single HTML file with no build step. Fonts are bundled in `fonts/`, `sw.js` is the offline cache, and `manifest.webmanifest` plus `icons/` make it installable.
